HALLO, LIEBE BAND!

Ein Platz für eure Neuigkeiten.

Homepage, Verwaltung und Dateien liegen gemeinsam auf GitHub. Zum Bearbeiten meldest du dich mit einem GitHub-Zugangsschlüssel an.

Der Schlüssel gilt nur in dieser geöffneten Verwaltung. Er wird weder im Repository noch im Browserspeicher abgelegt.

Zum ersten Mal hier? Zugang einrichten
  1. Öffne die Einrichtung bei GitHub ↗ und melde dich dort an.
  2. Bei Repository access wähle Only select repositories und dann bumbumtschak.
  3. Unter den Repository-Berechtigungen muss Contents: Read and write eingestellt sein. Weitere Schreibrechte sind nicht erforderlich.
  4. Klicke auf Generate token, kopiere den angezeigten Schlüssel und füge ihn oben ein. Bewahre ihn in deinem Passwortmanager auf; GitHub zeigt ihn nur einmal. Nach Ablauf kannst du hier einen neuen erstellen.

Den Schlüssel nur hier in der Verwaltung eingeben. Zum Ansehen und Spielen brauchen Besucher keinen Zugang.
